# Mystical

Mystical is a lightweight desktop launcher that unifies your **Steam** and **Epic Games** libraries into one clean interface.

## Features (planned)
- Browse combined Steam + Epic libraries
- Filter games (installed, owned, etc.)
- Fetch covers and assets automatically
- Launch directly from the app
- Lightweight, responsive, modular design

## Tech
- **Python 3.10+**
- **PySide6** (UI)
- **multiprocessing** for smooth background tasks
- **Legendary (optional)** for Epic library

## Setup
```bash
git clone https://github.com/yourname/mystical
cd mystical
python -m venv .venv
source .venv/bin/activate   # or .venv\Scripts\activate on Windows
